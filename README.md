# Zalo SOP Compliance — dashboard demos

| Dashboard | Link |
|---|---|
| Optometry — weekly outreach sent check | https://kohsinlong.github.io/zalo-sop-dashboard/ |
| Lasik — QC audit, D1–D25 | https://kohsinlong.github.io/zalo-sop-dashboard/lasik/ |

Each answers one question about the Zalo follow-up SOP.

**Optometry** — how many scheduled follow-ups were never sent? Due counts and
data flags come from the live Membership tracker; sent/not-sent figures are
placeholders until the Salework Zalo API is enabled.

**Lasik** — how many cases met the SOP standard of four or more touchpoints out
of five? Every touchpoint score is real, taken from the QC workbook (249 cases,
10 clinics). Audit dates are generated, since the workbook records none.

Static HTML, no dependencies. Language: EN / Tiếng Việt / 中文.
No patient data appears in either page.
